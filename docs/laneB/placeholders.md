> How lane B was joined with lanes A, C and D, and what replaced the placeholders it started with: [INTEGRATION_NOTES.md](INTEGRATION_NOTES.md).

Every placeholder of lanes A and C and of the link, telemetry and input parts of lane D is gone: those files are the owning lane's real code. What remains stands in for **Phase 2 and Phase 3 work of lane A and lane D that does not exist in this repository yet**: the Lung beat director, lane D's case package and the data it ships. Find them with `git grep -l "PLACEHOLDER (lane"`; each carries the header

`// PLACEHOLDER (lane X, <task id>): contract surface only; replaced by lane X's implementation`

(the data files and the generator carry the same sentence in their `README.md` or header). Lane B code uses only the public surface listed below. Tags: [plan] fixed by the Master Plan (MP); [min] the smallest choice, id PH-n.

## Assumptions still to confirm

### Lane A (P2-A32, the Lung director)
- A9. `ILungBeat` / `LungBeat` names and members; no P2-A26 signal; S6 is requested through `ISpaceHost` (PH-13, PH-14).

### Lane D (Phase 2 and 3 data)
- D3. Case location `StreamingAssets/cases/<id>`, fixture id "illustrative", `CaseManifest` reader assembly and fields (PH-33); `sky.json` under `sky/` (PH-34).
- D4. **PH-39, needs a human decision.** P2-D07 says "exactly 1 Two Compasses fork on the 4-fork route". With the plan geometry (37°, plane rotation 90°, ratio 0.794) and the Euclidean compass rule the route never has a wrong fork at depth 4 (0 of 299 seeds × 16 targets), so the fixture target is at generation 6. Agent rule 7 (MP §9.9): a number that cannot be met is reported, not relaxed. Either change the compass or target-point rule with an announcement, or accept 6 forks. The fixtures do not claim the P2-D07 pass. `tree.json` top level, `pos_mm` = proximal-start convention (the generator uses the parent's distal end), the compass rule (PH-35); tree depth 16 and Git LFS for `cases/**` (PH-36).
- D5. Sky layout: equirectangular orientation and patient frame, `mm_per_unit` 0.2, `sky.json` fields, whether checks hold pre-quantisation floats (PH-37).
- D6. Field mask location, scale (4 px/deg), polarity and orientation (PH-38). `FieldFitSettings.maskHalfWidthDeg` must match the preset (DV-B04-c).
- D7. **The FMS source for P2-B05's automatic Mode 2 rule is unspecified.** Lane B reads an `fms` event on the phone's log; lane D's `fms` is Hub-only and never sent to the phone (lane D §2.6). A channel is needed (a parameter, an operator command or a message). Nothing was invented.
